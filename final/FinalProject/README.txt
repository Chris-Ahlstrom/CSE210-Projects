To maneuver the menus, use the up and down arrow keys to move the * cursor to the option you want and press enter.
However, in the DisplayCards method in the Deck class, I included pagination so the list is capped at 10 entries
so if there are more than 10 unique cards in the deck you will need to use the right and left arrow keys to move between the pages.
When asked about the mana cost, for lands put 0, and for any other cards put the generic cost as is, and for color specific mana
use the WUBRG abbreviations (W = White, U = Blue, B = Black, R = Red, and  G = Green).

The program will launch with warning that certain attributes are never used and that's because I included them earlier on
and then decided to cut the functionality that utilized it because I either didn't have the time, or wasn't entirely sure
how to implement it.

I have included a partial decklist, which will let you test all of the functionality without requiring me to enter 100 cards worth of data.
